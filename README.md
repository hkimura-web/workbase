# THE WORKBASE

授業の予定と記録を管理するWebアプリです。データはこのリポジトリの `data/*.json` に入り、記録するたびに自動でコミットされるので、いつ何を直したかが履歴として残ります。

- **今日**：クラスごとの残り授業時間、今日と1週間の授業、これからの行事
- **計画表**：コマをタップして「実施／途中まで／休講／別の内容／行事で授業なし」を記録。休講にすると、以降の計画が自動で後ろへずれる
- **一覧**：日付を縦、担当の授業を横に並べた表。スプレッドシートのように、全クラスの前後を一目で見渡せる（科目ごとの並べ替えもできる）
- **単元別**：単元ごとの配当・計画・実施時間、学期末の振り返りメモ
- **サマリー**：授業ごとに、学期の「いつ・何をやったか」を1画面にまとめる

## 初回の準備（15分ほど）

1. GitHubで新しいリポジトリを作る（例：`jugyo-diary`）。
2. このフォルダの中身をすべてアップロードする（`index.html`、`css/`、`js/`、`data/`、`tools/`、`.github/`、`.nojekyll`）。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **Deploy from a branch** にし、Branch を **main**、フォルダを **/ (root)** にして Save する（GitHub Actions を使う方法もあり、`.github/workflows/pages.yml` が用意してあります）。しばらくして `https://<ユーザー名>.github.io/<リポジトリ名>/` が開けば公開完了。
4. 記録をGitHubに保存するための**アクセストークン**を作る。
   - GitHub右上のアイコン → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access は **Only select repositories** でこのリポジトリだけを選ぶ
   - Permissions → Repository permissions → **Contents: Read and write**
   - 期限は好きな長さでよい（切れたら作り直す）
5. アプリを開き、右上の **設定** にユーザー名・リポジトリ名・トークンを入れて「保存して反映」。画面上部が「GitHubに保存済み」になれば完了。

トークンは、その端末のブラウザの中だけに保存されます（リポジトリには入りません）。スマホでも使う場合は、スマホでも同じ設定をします。

## ほかのパソコンやスマホで使う

データはGitHubのリポジトリにあるので、どの端末からでも同じ記録を見られます。端末ごとに必要なのは、アプリのアドレスを開いて、右上の「設定」にアクセストークンを貼り付けることだけです。別の端末で直した記録は、その端末に画面を戻したときに自動で取り込まれます。共用のパソコンで使ったあとは、「設定」の「この端末の設定を消す」を押してください。

## 使い方のポイント

- 記録を直すと、1〜2秒後に自動でGitHubへ保存されます。画面上部で保存状態を確認できます。
- 通信できないときや、設定していないときは、この端末のブラウザに下書きが残ります。
- 別の端末で先に更新していた場合は、バナーで「上書き保存」か「最新を読み込む」を選べます。
- 基準日は、ふだんは今日です。日付を動かすと、その日から先の予測に切り替わります。
- 設定の「JSONを書き出す／読み込む」で、手元にバックアップを取れます。

## 公開範囲について

GitHub Pagesの無料プランでは、サイトを公開できるのは**公開リポジトリ**です。公開にする場合は、生徒の氏名・成績などの個人情報を入れないでください（授業の内容・進度・行事予定だけなら、このアプリのデータで足ります）。非公開のまま使いたいときは、GitHubの有料プランで非公開のPagesにするか、Pagesを使わずに手元で動かします（下記）。

## 手元で動かす

```
python3 -m http.server 8000
```
を、このフォルダで実行し、http://localhost:8000/ を開きます。`index.html` をファイルとして直接開くと、データを読めません。

## 次の学期のデータを作る

元のスプレッドシート（Excelでダウンロードしたもの）から、変換できます。

```
pip install openpyxl
python3 tools/xlsx_to_json.py 授業時間数_計画.xlsx --sheet "3学期(2026)" \
  --id 2026-3 --name "2026年度 3学期" --start 2027-01-11 --end 2027-03-04 \
  --asof 2027-01-11 --rules tools/rules-2026-2.json --out data/2026-3.json
```

そのあと `data/index.json` に1行足すと、画面の「学期」から切り替えられます。

```json
{ "id": "2026-3", "name": "2026年度 3学期", "file": "2026-3.json" }
```

単元名は `tools/rules-2026-2.json` の規則で推定しています（内容にキーワードがあれば単元名を付ける）。推定が合わなければ、アプリの「単元別」で名前を直せます。

## ファイル構成

| パス | 役割 |
|---|---|
| `index.html`, `css/`, `js/` | アプリ本体（ビルド不要） |
| `data/index.json` | 学期の一覧 |
| `data/2026-2.json` | 2026年度2学期のデータ |
| `tools/xlsx_to_json.py` | スプレッドシート → JSON の変換 |
| `tests/logic.test.js` | 計画のずれ方などの確認（`node tests/logic.test.js`） |
| `.github/workflows/pages.yml` | GitHub Pagesへの自動公開 |

## 一覧タブの使い方（編集モード）
- 太い枠＝その日に授業があるコマ。今日の授業はオレンジ。行事は「行事」、授業なしは「休校／授業なし」と理由を表示。
- 「編集」モードでは、コマの中で 状態（実施・途中・休講・別・予定・なし）／単元／授業内容／記録 を直接入力。単元の予定（単元別タブ）はコマの2つ目のプルダウンで選べる（使用済みは✓）。
- 「詳細」で順番の入れ替え・削除など。「見るだけ」で一覧表示に切り替え。

## 前の学期から引き継ぐ（次の年度の計画案づくり）
1. 新しい学期のデータ（日付・時間割・行事）を、スプレッドシートから今までどおり取り込む（`data/` に学期ファイルを置き、`data/index.json` に学期を追加）。
2. 新しい学期を開き、一覧の「前の学期から引き継ぐ」を押す。
3. 引き継ぎ元の学期とクラスの対応を選び、単元ごとに「計画」「実績」の時間を選んで実行。
   計画の順番・授業内容・単元・教材リンクが写り、前回の計画／実績／振り返りメモは単元別タブに残る。

## 校務モード（授業｜校務の切り替え）
- 画面の「授業／校務」ボタンで切り替えます。校務の中は ホーム・年間・リンク集・手順メモ・カレンダー・設定。
- 校務のデータは `data/work.json`（GitHub接続後、最初に直したときに自動で作られます）。リンク集の元は `work/links.json`。
- リンク集の作り直し: `python3 tools/xlsx_to_work.py ポータル.xlsx work/links.json`（パスワード類は自動で除外）。
- 「1年間の仕事」アプリのバックアップ(.json)は、校務の「設定」から読み込めます。

## テスト成績モード（第3のモード）
- 上の「授業｜校務｜テスト成績」で切り替え。テスト期間だけ使う、試験準備〜成績会議の工程管理です。
- データは `data/seiseki.json`（初めて使うときは、画面のボタンで作ります）。コードは `js/seiseki.js`。
- 試験の初日・成績提出・成績会議の日を入れると、22件の作業が逆算で並びます。期限が近い作業は「授業」の今日タブにも出ます。

## 勤怠モード（第4のモード）
- 有給・超過勤務・振替時間休・振替休日・行事予定。データは `data/kintai.json`、コードは `js/kintai.js`。
- 行事予定は授業側の行事と1つにまとまり、カレンダーでは授業のコマ数を見ながら振替日を決められます。

## 重要Tips（共通の帯）と手順・メモ

- 授業・校務・テスト成績の3つに、それぞれ「手順・メモ」があります。メモに ★ を付けると、授業の「今日」・校務のホーム・テストのホームの一番上の「重要Tips」に出ます（勤怠には出しません）。
- 帯は、いま開いているモードのTipsが先、ほかは「ほかのTips」に折りたたまれます。色：授業=青、テスト=ピンク、校務はタグごと（クラス=緑、タグなし=白など）。
- 帯の右上：「さがす」（文字を入れると3モード全部から絞り込み）／「並べ替え」（ボタンをつかんで同じ段の中で動かす）／「手順・メモを開く」。
- 授業のメモには「今日の授業で目立たせる言葉」を入れられます。今日の授業の単元名・クラス名に含まれると「今日」のしるしがついて先頭に来ます。
- タグは3モードとも自分で増やせます（「タグを管理する」）。校務の元のタグは「元の色」のまま、増やしたタグは8色から選べます。
- データ：授業のメモ=`data/jugyomemo.json`（初回の保存で自動作成）、校務=`data/work.json`、テスト=`data/seiseki.json`。
- 校務のメモのうち、タグ「授業」は授業へ、タグ「テスト成績」はテスト成績へ、アプリを開いたとき一度だけ自動で移ります（画像つきも移ります）。

## 2時間続きの授業は、1時間ずつのコマ

- 1日に2時限以上ある授業は、「5時間目」「6時間目」のように、1時限ごとに別のコマとして表示・記録します（今日・計画表・一覧・サマリー・単元別すべて）。
- 記録のキーは「クラス|日付|時限」。1時限だけの日は今までどおり「クラス|日付」です。
- 古いデータ（2時間をひとまとめに記録したもの）は、開いたときに自動で各時限に移ります（途中までは最後の時限だけ、記録メモは最初の時限だけ）。計画の割り当てや時数は、これまでの全学期のデータで変わらないことを確認済みです。
- 2時間ぶんで作った計画ブロック（h=2）は、2コマにまたがって表示され、2コマ目は「（続き）」と出ます。
- 「行事で授業なし」は、同じ日の同じクラスの全時限にまとめて付きます。

## 特別日課（短縮授業・模試・面談週間）

- 授業の「一覧」の「特別日課」ボタンで、その日だけ時間割が変わる日を入れます（名前・期間・授業なしにする時限・授業時間）。
- 「授業なしにする時限」は授業なしになり、計画は自動で後ろへずれます。「授業時間を変える」を入れると、1限の開始・1コマの長さ・休みから、「今日」の時刻表示（いま／次の授業）も変わります。
- 年によって変わるので、いつでも直せます。データは学期のファイル（`st.days`）に入ります。
- 2026年度2学期だけ、最初に来週（11/9〜13）の面談週間・模試が入っています（9・10・13日＝40分授業で5限以降なし、11・12日＝模試で全部なし）。

## 毎年のくり返しノート（校務の「くり返し」タブ）

- 毎年同じ時期にあること（面談週間・模試・短縮授業など）を、年度ごとにノートとして貯めます（名前・期間・内容・資料リンク・「毎年ある／たぶん毎年／今年だけ」）。データは `data/yearly.json`（初回の保存で自動作成）。
- 次の年になると、先頭に「去年の同じ時期にあったこと」が出ます（これから75日以内のもの）。52週ぶんずらした「今年の同じ週」の日付が出て、「今年に取り込む」で写せます（日付は1日ずれることがあるので、写したあとで直してください）。
- ノートに「授業の特別日課」を写しておけます（「授業の特別日課を写す」）。次の年は「授業の特別日課に入れる」で、いま開いている学期の授業に一度に入れられます。
- 最初に、2026年度の面談週間（11/9〜13）が入っています。
