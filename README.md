# WORKBASE

仕事で使う資料・マニュアル・外部サービスへのリンクをまとめた、自分用のポータルサイトです。
スプレッドシート（全データPortal）をアプリ化したものです。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（検索・絞り込み・今月やること・ピン留めなど） |
| `links.json` | リンクのデータ。**日常の更新はこのファイルだけ編集する** |
| `README.md` | このファイル |

## 主な機能

- **検索**：ひらがな・カタカナどちらでも検索可。スペース区切りで絞り込み
- **分類ボタン**：領域別、または「★重要」で絞り込み
- **今月やること**：月ごとの定例業務と関連リンクを表示（月は切り替え可）
- **ピン留め／最近開いた**：使っているブラウザ内に保存（端末ごとに別管理）
- **リンク追加ヘルパー**：画面下部で、`links.json` に貼る1行を作成

## 公開方法（GitHub Pages）

1. GitHubでリポジトリを作成し、上の3ファイルをアップロード
2. `Settings` → `Pages` → `Branch: main` / `/ (root)` を選んで保存
3. 表示されたURLをブックマーク（スマホはホーム画面に追加）

※ 無料プランのGitHub Pagesはサイトが公開状態になります。URLを知っている人には、リンクのタイトル一覧が見えます。リンク先のGoogleドライブ等は、共有設定により第三者は開けません。
パスワードやIDは `links.json` に入れないでください。

## links.json の書き方

```json
{
  "updated": "2026-10-31",
  "links": [
    { "id": 124, "title": "資料名", "url": "https://...", "cat": "国語科", "imp": 1, "note": "メモ（任意）" }
  ],
  "monthly": [
    { "months": [3], "task": "指導要録の作成", "match": "要録" }
  ]
}
```

| 項目 | 説明 |
| --- | --- |
| `id` | 他と重ならない数字（ピン留めの識別に使用） |
| `title` | 表示名 |
| `url` | リンク先 |
| `cat` | 分類。新しい名前を書くと分類ボタンが自動で増える |
| `imp` | `1` で「重要」表示、`0` で通常 |
| `note` | 補足メモ（検索対象にもなる。省略可） |

### 今月やること（monthly）

- `months`：表示する月（例：`[9, 10, 11]`）
- `task`：やることの名前
- `match`：この語をタイトルに含むリンクを自動で表示

## 更新の流れ

1. GitHubで `links.json` を開き、鉛筆アイコンで編集
2. 追加・修正して `Commit changes`
3. 数十秒後にサイトへ反映

## 年度替わりのメモ

- 古くなったリンクは削除するか、`note` に「2025年度」などと書いて区別
- `monthly` の `match` が今年度の資料名と合っているか確認
- `updated` の日付を更新

## 動作確認について

`index.html` を直接開いた場合は、ファイル内に埋め込んだデータのコピーを表示します。`links.json` の編集内容が反映されるのは、GitHub Pagesなどで公開したときです。
